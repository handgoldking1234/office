# 바로오피스

광고·로그인 없이 휴대폰 브라우저에서 엑셀(.xlsx .xls .csv)과 PPT(.pptx)를 열고 고쳐서 다시 내려받고, PDF·워드(.docx)는 바로 열어 보는 웹 오피스.
파일은 서버로 보내지 않고 브라우저 안에서만 처리합니다.

## 구성
- `index.html` — 앱 전체(단일 파일). SheetJS·JSZip은 cdnjs, PptxGenJS(새 PPT 만들기)는 jsDelivr에서 불러옴
- `manifest.webmanifest`, `icon-*.png` — 홈 화면에 추가(PWA)용

## 기능
- 엑셀: 셀 값·수식 수정(SUM·AVERAGE·IF·SUMIF 등 자동 계산), 시트 이동, 확대·축소. 원본 xlsx는 바뀐 셀만 고쳐 서식 유지
- PPT: 캔버스에서 끌어서 이동·모서리로 크기 조절, 속성 패널(위치·크기·회전·채우기·테두리·글자 크기/굵게/기울임/밑줄/정렬/색), 글상자·사각형·원·이미지 넣기, 실행 취소/다시 실행, 슬라이드 추가·복제·삭제·순서·배경색, 발표 모드
- 디자인 패널: 슬라이드 기준 정렬 6종, 좌우·상하 뒤집기, 비율 고정, 불투명도, 모서리 둥글기, 테두리 실선·파선·점선, 그림자 4단계, 줄 간격, 세로 정렬, 색상 코드 입력, 한 단계 앞/뒤, 캔버스 확대·축소
- 도구막대: 선택·글상자·도형 33종(기본·화살표·별·말풍선·선)·펜·이미지·표 / 왼쪽 패널에 슬라이드·레이어 탭
- PC(900px 이상): 왼쪽 슬라이드 목록 + 가운데 캔버스 + 오른쪽 속성 패널 + 떠 있는 도구막대, 단축키(T·R·O, Ctrl+Z, Ctrl+D, 방향키, Delete)
- PDF: 글자·그림(서명) 넣기, 쪽 회전·삭제·순서 변경 후 저장 (pdf.js로 보기, pdf-lib로 저장)
- PDF 가리기 상자: 원래 글자를 흰 상자로 덮고 새 글자를 올리는 방식
- 워드(.docx): 문단을 눌러 바로 고치기(Enter로 문단 나누기, Backspace로 합치기), 굵게·기울임·밑줄·정렬·글자 크기. 원본 document.xml의 바뀐 문단만 수정
- 휴대폰 폴더 연결(지원 브라우저): 고른 폴더의 파일을 최근 순 카드로 표시, 원본에 바로 저장
- 그리기 도구: 도형·선·글상자를 슬라이드 위에서 끌어서 그리기, 펜(자유 곡선), 복사·잘라내기·붙여넣기(슬라이드 간, 슬라이드 자체)
- 아이콘: Lucide (ISC License)
- 최근 파일 20개를 브라우저(IndexedDB)에 자동 보관

## 카톡 등 다른 앱에서 바로 열기
- `manifest.webmanifest`의 `share_target` + `sw.js`: 홈 화면에 설치(안드로이드 크롬)하면 다른 앱의 공유 목록에 바로오피스가 나오고, 공유한 파일이 바로 열림
- 사이트 루트(`/`)에 배포해야 동작 (`/share`, `/sw.js` 경로 사용)

## 엑셀 서식 (xlsx)
- 서식 도구막대: 실행 취소/다시 실행, ₩·%·소수 자릿수·천 단위, 글자 크기, 굵게·기울임·취소선, 글자 색·채우기 색, 테두리, 셀 병합, 가로·세로 맞춤, 줄 바꿈, 함수(SUM 등) 넣기
- 범위 선택(드래그, Shift+클릭, 행·열 머리글, 모바일 범위 버튼), 복사·잘라내기·붙여넣기(다른 앱과 호환)
- 원본 styles.xml을 읽어 굵게·색·테두리·맞춤을 화면에 표시하고, 바꾼 서식은 새 cellXfs로 추가해 저장
- 시트에 놓인 그림 표시, 차트는 자리만 표시

## PPT 추가 기능
- 글꼴·취소선·양쪽 정렬·글머리 기호/번호·들여쓰기, 찾기·바꾸기, 서식 복사, 레이아웃을 골라 새 슬라이드

## 저장
- 고칠 때마다 브라우저(IndexedDB)에 자동 보관
- 파일 선택 창·폴더 연결로 연 파일은 '원본에 저장'을 한 번 고르면 이후 고칠 때마다 원본 파일에 자동 저장 (File System Access 지원 브라우저)
- 그 외에는 내려받기로 사본 저장
